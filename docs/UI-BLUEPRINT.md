# OtogeTrainer — UI 청사진

- **버전**: v0.1 (기획 초안) · 2026-09-15
- **상위 문서**: [SPEC.md](../SPEC.md)

---

## 1. 설계 원칙

| 원칙 | 의미 |
|---|---|
| **영상이 주인공** | 재생 화면에서 크롬(UI 장식)은 최소. 컨트롤은 마우스가 멈추면 2.5초 후 사라진다 |
| **상태는 항상 보인다** | 배속 · 오프셋 · 단축키 동작 여부는 영상 위 OSD에 상시 노출. "지금 뭐가 걸려 있는지" 모르는 상태를 만들지 않는다 |
| **재생 중엔 키보드가 없다고 친다** | 재생 중 앱은 ESC 외 키에 반응하지 않으므로, 모든 기능이 마우스로 도달 가능해야 한다 |
| **다크 온리** | 게임 캡처는 대부분 어두운 화면. 밝은 UI는 잔상과 눈부심을 만든다 |
| **두 번의 클릭** | 앱 실행 → 최근 영상 클릭 = 어제 그 지점 |

## 4. 플레이어 — 일시정지 상태 (컨트롤 표시)

```
┌────────────────────────────────────────────────────────────────────────────────┐
│ ◀ 라이브러리    conflict_HARD_2026-09-14.mp4          🔓 단축키 사용  ─ □ ✕    │
├────────────────────────────────────────────────────────────────────────────────┤
│                                                     ┌────────────────────────┐ │
│                                                     │ 1.00x   ⏱ +33ms        │ │  ← OSD (우상단)
│                                                     │ 00:02:14.383  f#8063   │ │
│                                                     └────────────────────────┘ │
│                                                                                 │
│                          ( 영상 렌더 영역 )                                     │
│                                                                                 │
│  ─────────────────────────────────────────────────────────  ← 가이드 라인(옵션) │
│                                                                                 │
│                                                                                 │
│   ┌──────────────────────────────────────────────────────────────────────────┐ │
│   │ ═══════◆═══════════╋════════▌▌▌▌▌▌▌▌▌▌▌════════════╋══════════════════   │ │  ← 타임라인
│   │        1           2        └─ A-B 루프 구간 ─┘    3                      │ │     ◆=커서
│   │ 00:02:14.383                                              00:04:21.000   │ │     숫자=북마크
│   ├──────────────────────────────────────────────────────────────────────────┤ │
│   │  ⏮5s  ◀❙ 1f    ▶ 재생    1f ❙▶   5s⏭   │  0.50x ◀ ▶  [1.0]              │ │
│   │                                          │                                │ │
│   │  🔖 1 2 3 4 5   ⇄ A-B   ⏱ 오프셋   📏 가이드   🔇 🔊 ───●──   📌 ⛶      │ │
│   └──────────────────────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────────────────────┘
```

### 컨트롤 바 구성

| 그룹 | 컨트롤 | 동작 |
|---|---|---|
| 탐색 | `⏮5s` / `5s⏭` | 5초 × 현재 배속 점프 (버튼 라벨은 실제 값으로 갱신: 0.5x면 `⏮2.5s`) |
| 탐색 | `◀❙ 1f` / `1f ❙▶` | 프레임 스텝. 누르고 있으면 반복 |
| 재생 | `▶ / ❚❚` | 재생·일시정지 |
| 배속 | `0.50x ◀ ▶` | 0.05 단위 증감. 숫자 클릭 시 프리셋 드롭다운 |
| 배속 | `[1.0]` | 원클릭 1.0배속 복귀 |
| 북마크 | `🔖 1 2 3 4 5` | 채워진 슬롯은 밝게. 클릭=점프 / `Ctrl+클릭`=현재 위치 저장 / 우클릭=메뉴(저장·라벨·삭제) |
| 루프 | `⇄ A-B` | 클릭 1회=A 지정, 2회=B 지정 및 루프 시작, 3회=해제. 우클릭=루프 설정 패널 |
| 오프셋 | `⏱ 오프셋` | 팝오버(§6) |
| 오버레이 | `📏 가이드` | 가이드 라인 편집 모드 토글 |
| 기타 | `🔇` 음소거 / 볼륨 / `📌` 항상 위 / `⛶` 전체화면 | |

> **재생 중에는 예외 키가 없으므로([D-4](DECISIONS.md#d-4-재생-중-차단의-예외)), 음소거 · 볼륨 · 항상 위 · 전체화면이 컨트롤 바에 반드시 노출되어 있어야 한다.** 여기서 빠지면 재생 중 그 기능에 도달할 방법이 사라진다.

### 타임라인

- 북마크 마커: 슬롯 번호가 적힌 작은 삼각형. 드래그로 미세 이동.
- A-B 구간: 반투명 밴드로 하이라이트. 양 끝 핸들 드래그 가능.
- 호버 시 해당 지점 시각 툴팁 (`00:03:12.500`).
- 드래그 중에는 실시간 시크하지 않고(스크럽 부하 방지) 놓을 때 exact seek. `Shift+드래그`면 실시간 스크럽.

### OSD (우상단)

항상 표시: `배속` · `오프셋(0이 아닐 때만)` · `타임코드` · `프레임 번호`.
VFR 영상이면 프레임 번호 옆에 `~` 표시 + 툴팁 "가변 프레임레이트 — 추정값".

## 5. 플레이어 — 재생 중 (단축키 차단)

```
┌────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│                      ┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓                      │
│                      ┃  🔒  재생 중 · 단축키 잠시 꺼짐    ┃   ← 재생 시작 후    │
│                      ┃      ESC 를 누르면 일시정지        ┃      3초간 또렷하게,│
│                      ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛      이후 사라짐     │
│                                                                                 │
│                                                                                 │
│                          ( 영상 렌더 영역 )                                     │
│                                                                                 │
│                                                                                 │
│                                                        ┌──────────────────────┐│
│                                                        │ 0.50x  ⏱+33ms  🔒    ││
│                                                        │ 00:02:14.383 f#8063  ││
│                                                        └──────────────────────┘│
│                                                                                 │
│      (마우스를 움직이면 컨트롤 바가 나타남 — 마우스 조작은 그대로 동작)          │
└────────────────────────────────────────────────────────────────────────────────┘
```

### 상태 배지 2종

| 재생 상태 | 배지 | 의미 |
|---|---|---|
| 재생 중 | 🔒 **단축키 꺼짐 · ESC로 일시정지** | 키를 눌러도 앱이 반응하지 않음 (예외 키 없음) |
| 일시정지 | 🔓 **단축키 사용** | 프레임 스텝 · 북마크 등 전체 단축키 동작 |

> 다른 프로그램의 키보드 동작은 어느 상태에서도 전혀 건드리지 않는다.
> `Win`, `Alt+Tab`으로 나가면 평소 그대로다.

### 전환 피드백

- **재생 시작**: 배지가 🔒로 바뀌며 3초간 강조 후 사라짐. 화면 가장자리 앰버 테두리(2px, 투명도 25%)를 재생 중 유지 — 곁눈으로도 상태를 알 수 있게.
- **ESC / 일시정지**: 테두리 사라짐 + 배지 🔓 + 하단 토스트 `일시정지 · 단축키 사용 가능` (1.5초).
- 소리 피드백 없음 (연습 중 소리 방해 금지).
- 설정에서 "재생 중에도 단축키 허용"(FR-508)을 켜면 배지와 테두리는 표시되지 않는다.

## 6. 오프셋 팝오버

```
        ┌──────────────────────────────────────────────┐
        │  A/V 오프셋                             ✕    │
        ├──────────────────────────────────────────────┤
        │                                              │
        │          ◀◀   ◀    +33 ms    ▶   ▶▶          │
        │         −25  −5            +5  +25           │
        │                                              │
        │   ≈ 2.0 frames @ 60fps                       │
        │                                              │
        │   −1000 ├────────────●───────────────┤ +1000 │
        │                                              │
        │   양수 = 소리를 늦춤                          │
        │   (소리가 영상보다 빨리 들릴 때 올리세요)      │
        │                                              │
        │   [ 0으로 초기화 ]   [ 이 폴더 기본값으로 저장 ]│
        │                                              │
        │   적용 우선순위: 이 영상 > 폴더 > 전역         │
        └──────────────────────────────────────────────┘
```

- 값 변경은 **즉시 반영 + 즉시 저장** (확인 버튼 없음).
- 재생 중에도 열어둔 채 조절 가능 — 팝오버는 영상을 가리지 않도록 우하단 배치.

## 9. 키 매핑 (일시정지 상태에서만 동작)

> 재생 중에는 `ESC`를 제외한 아래 전부가 **앱 안에서만** 무시된다. 예외 키는 없다([D-4](DECISIONS.md#d-4-재생-중-차단의-예외)).
> 다른 프로그램에는 영향이 없으며, 키보드의 미디어 볼륨 키는 앱이 가로채지 않으므로 재생 중에도 동작한다.

| 키 | 동작 | FR |
|---|---|---|
| `Space` | 재생 / 일시정지 | FR-201 |

| `Alt+←` | 라이브러리로 복귀 (상태 저장) | FR-511 |
| `←` / `→` | 5초 × 배속 뒤 / 앞 | FR-303 |
| `,` / `.` | 1프레임 뒤 / 앞 | FR-301 |

| `Ctrl+,` | 설정 | FR-701 |
| `Ctrl+O` | 파일 열기 | FR-101 |

> 모든 바인딩은 설정에서 변경 가능(FR-701). 충돌 시 저장 버튼이 비활성화되고 충돌 대상을 표시한다.

### 마우스 매핑 (재생 중 · 일시정지 공통)

SPEC §6.6 표 참조. **재생 중에도 전부 동작한다** — 재생 중 조작의 주 경로이므로 누락되면 안 된다.

## 10. 설정 창

```
┌─ 설정 ───────────────────────────────────────────────────────┐
│ ┌──────────┐                                                  │
│ │ 일반     │   ▸ 시작 화면 : [ 라이브러리 ▾ ]                 │
│ │ 재생     │   ▸ 언어      : [ 한국어 ▾ ]                     │
│ │ 입력     │   ▸ 데이터 위치: %APPDATA%\OtogeTrainer  [열기]  │
│ │ 단축키   │   ▸ ☐ 포터블 모드 (exe 옆 data\ 사용)           │
│ │ 라이브러리│                                                  │
│ │ 정보     │                                                  │
│ └──────────┘                                                  │
└───────────────────────────────────────────────────────────────┘
```

| 탭 | 항목 |
|---|---|
| **일반** | 시작 화면, 언어, 데이터 위치, 포터블 모드, 테마(다크 고정 / 시스템) |
| **재생** | 기본 배속, 피치 보정 on/off, 점프 기준값(초), **점프 배속 연동 on/off**, 큰 점프 값, 프레임 스텝 반복 속도, 영상 종료 시 동작, 하드웨어 디코딩, 출력 드라이버 |
| **입력** | **☐ 재생 중에도 단축키 허용**(기본 OFF, FR-508), 재생 중 상태 배지/테두리 표시 여부, 마우스 제스처 on/off, 휠 동작 선택(점프 / 볼륨), 게임패드(P2) |
| **단축키** | 전체 바인딩 목록 + 충돌 검사 + 기본값 복원 |
| **라이브러리** | 등록 폴더 관리, 폴더별 기본 오프셋, 최근 목록 개수, 썸네일 캐시 크기/비우기, 시작 시 스캔 |
| **정보** | 버전, 사용 중인 libmpv 버전, 오픈소스 라이선스 고지, 로그 폴더 열기 |

## 11. 비주얼 가이드

### 색상 (다크)

| 토큰 | 값 | 용도 |
|---|---|---|
| `bg-0` | `#0E0F12` | 앱 배경 |
| `bg-1` | `#16181D` | 카드 · 패널 |
| `bg-2` | `#1E2127` | 입력 · 호버 |
| `fg-0` | `#E8EAF0` | 본문 |
| `fg-1` | `#9AA0AC` | 보조 |
| `accent` | `#4DA3FF` | 주요 액션 · 재생 커서 |
| `warn` | `#FFB454` | **재생 중 단축키 차단 표시(앰버)** |
| `bookmark` | `#7C5CFF` | 북마크 마커 |
| `loop` | `#2ED3A0` | A-B 구간 밴드 |
| `danger` | `#FF5C5C` | 파일 없음 · 오류 |

> 재생 중 차단 상태는 의도적으로 `accent`가 아닌 **앰버**를 쓴다. "지금 키가 안 먹는 상태"라는 신호가 색만으로 전달되어야 한다.

### 타이포

- UI: **Pretendard** (없으면 `Segoe UI Variable` → `맑은 고딕` 폴백)
- 타임코드 · 프레임 번호 · 오프셋: **등폭**(`Cascadia Mono` → `Consolas`). 숫자가 흔들리면 프레임 탐색이 피로해진다.
- 최소 본문 12.5pt, OSD 13pt (전체화면 시 스케일 업)

### 모션

| 대상 | 시간 |
|---|---|
| 컨트롤 바 페이드 인 / 아웃 | 120ms / 240ms (마우스 정지 2.5초 후) |
| 패널 슬라이드 | 180ms, ease-out |
| 토스트 | 표시 150ms, 유지 1.5초, 소멸 300ms |
| 재생 중 테두리 페이드 인 / 아웃 | 400ms |

**재생 중 화면 위 애니메이션은 이 목록이 전부.** 연습 중 시선을 뺏는 요소를 추가하지 않는다.

## 12. 오류 · 예외 상태 UI

| 상황 | 표현 |
|---|---|
| 코덱 없음 / 디코딩 실패 | 영상 영역에 정적 안내 + `하드웨어 디코딩 끄고 다시 시도` 버튼 |
| 파일 없음(이동/삭제) | 카드에 `⚠` 배지, 클릭 시 `다시 찾기` 대화상자 |
| 재생 중 단축키를 눌렀을 때 | **아무 반응도 하지 않는다.** 경고·깜빡임·소리 없음 (SPEC §6.3) |
| VFR 감지 | OSD 프레임 번호에 `~`, 최초 1회 툴팁 안내 |
| 긴 GOP로 역스텝 지연 | 프레임 스텝 버튼에 인라인 스피너 (200ms 초과 시) |
| 디스크/DB 쓰기 실패 | 토스트 + 로그 폴더 열기 링크. 재생은 계속 |
